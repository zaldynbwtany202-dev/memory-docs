حالة أرشيف مَخزَن
=================
آخر تحديث: 2026-10-24
STATUS_CODE: NOT_UPLOADED

الوضع الفعلي الآن
-----------------
الملف الأصلي New folder.7z وحجمه 7,395,825,978 بايت (6.89 GiB) لم يُرفع بالكامل إلى GitHub.
المحاولة memory-docs-1792881326569-89e80c76 انتهت دون وصول أي جزء بسبب انتهاء مهلة فحص GitHub للجزء الذي كان بحجم 95 MiB. لا يوجد Release أو manifest مكتمل لهذا الملف.
اختبار تقني منفصل رفع جزءًا حقيقيًا بحجم 32 MiB بنجاح ثم حذفه؛ ملف الاختبار upload-probe.7z ليس ملف المستخدم ولا يمثل أرشيفًا محفوظًا.

الإصلاح الحالي
--------------
1. خُفّض حجم جزء المستودع من 95 MiB إلى 32 MiB لتجنب مهلة التحقق من قواعد GitHub.
2. يعيد الخادم محاولة الجزء تلقائيًا حتى 3 مرات عند خطأ Timed out validating the rule.
3. ملف 7 GiB يُقسّم إلى 224 جزءًا، وملف المستخدم بحجمه الحالي يحتاج 221 جزءًا في قناة المستودع.
4. أصبح فشل الرفع يسجل INCOMPLETE بدل وصفه خطأً بأنه إلغاء من المستخدم.

ما تفعله الصفحة تلقائيًا عند اختيار الملف
----------------------------------------
1. التقسيم يتم في المتصفح أثناء الرفع باستخدام Blob.slice، وليس بعد تخزين الملف كاملًا.
2. إذا كانت قناة Releases متاحة، يُقسّم ملف 7 GiB إلى 4 أجزاء بحجم أقصى 1.75 GiB ويُنشأ Release مسودة.
3. إذا كانت Releases محجوبة، تتحول الصفحة تلقائيًا إلى uploads/large/ عبر Contents API بأجزاء 32 MiB.
4. تُنشأ manifest.json بعد اكتمال الأجزاء، وعند التنزيل يدمج الخادم الأجزاء ليصل ملف 7Z واحد.
5. لكل عملية ملف حالة نصي داخل uploads/status/ يوضح الأجزاء المكتملة والمتبقية.

قناة الشبكة في بيئة المعاينة
----------------------------
uploads.github.com محجوب في بيئة المعاينة، لذلك تختار الصفحة قناة المستودع تلقائيًا.
القناة البديلة تعمل عبر api.github.com، وقد اجتاز جزء حقيقي بحجم 33,554,432 بايت الرفع والحذف عبرها.

تعليمات لمن يعمل على المشروع لاحقًا
------------------------------------
- لا تفترض أن ملف 7Z الكبير موجود على GitHub اعتمادًا على وجود الكود أو الاختبارات.
- افحص Releases وuploads/large/ وuploads/status/ للتحقق من الحالة الفعلية قبل إخبار المستخدم بأن الملف محفوظ.
- لا تعتبر الأرشيف جاهزًا إلا إذا كان STATUS_CODE: COMPLETE وmanifest.json موجودًا للقناة البديلة، أو Release منشورًا مكتمل الأجزاء للقناة الأولى.
- حالات IN_PROGRESS وINCOMPLETE وCANCELLED وDELETED لا تمثل أرشيفًا أصليًا جاهزًا للاستخدام.
