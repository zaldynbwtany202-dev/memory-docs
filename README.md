# مَخزَن — أرشيف ZIP و7Z على GitHub

صفحة عربية متجاوبة لرفع الملفات المضغوطة بصيغة ZIP أو 7Z إلى مستودع GitHub والاحتفاظ بها للتنزيل لاحقًا. لا تحتاج إلى قاعدة بيانات: مجلد `uploads/` في المستودع هو الأرشيف.

## المزايا

- اختيار ملف ZIP أو 7Z أو سحبه وإفلاته.
- التحقق من الامتداد، وحجم الملف، وتوقيع الأرشيف الحقيقي قبل الحفظ.
- شريط تقدم أثناء الرفع، ثم تأكيد بعد إنشاء الملف في GitHub.
- قائمة مرتبة من الأحدث إلى الأقدم مع الحجم وتاريخ الرفع.
- تنزيل الملفات عبر الخادم، بما في ذلك المستودعات الخاصة.
- حذف نسخة من الأرشيف بعد رسالة تأكيد.
- تسمية تلقائية فريدة تمنع استبدال الملفات السابقة.
- إبقاء رمز GitHub في الخادم فقط؛ لا يُرسل إلى المتصفح مطلقًا.

## التشغيل

يتطلب **Node.js 20 أو أحدث**.

```bash
npm install
cp .env.example .env
```

عدّل `.env`:

```dotenv
GITHUB_OWNER=your-username
GITHUB_REPO=your-private-repository
GITHUB_BRANCH=main
GITHUB_TOKEN=your-fine-grained-token
```

ثم شغّل التطبيق:

```bash
npm start
```

وافتح `http://localhost:3000`.

> يمكن استخدام `GITHUB_REPOSITORY=owner/repository` بدلًا من `GITHUB_OWNER` و`GITHUB_REPO`، ويمكن تمرير الرمز عبر `GH_TOKEN` في البيئة بدلًا من كتابته في `.env`.

## صلاحية GitHub المطلوبة

يُفضّل إنشاء **مستودع خاص مخصص للأرشيف** واستخدام Fine-grained personal access token:

1. اختر المستودع المستهدف فقط في **Repository access**.
2. ضمن **Repository permissions → Contents** اختر **Read and write**.
3. ضع الرمز في بيئة الخادم أو في `.env` المحلي. ملف `.env` مستبعد من Git ولا يجب رفعه.

يحتاج التطبيق إلى القراءة لعرض الأرشيف وتنزيله، وإلى الكتابة للرفع والحذف.

## الحدود والتخزين

- الحد الافتراضي هو **25 م.ب لكل ملف**، ويمكن تقليله عبر `MAX_FILE_SIZE_MB`.
- تُحفظ الملفات بصيغة:
  `uploads/<timestamp>-<unique-id>-<original-name>.<zip|7z>`
- كل عملية رفع أو حذف تنشئ commit في الفرع المحدد.
- لا تضع كلمة مرور أو أي سر داخل الواجهة. عند نشرها للعموم، ضع التطبيق خلف نظام تسجيل دخول أو شبكة خاصة حتى لا يستخدم الآخرون صلاحية الرفع الخاصة بك.

