# مكتبة مراجع المذكرة

## أماكن الملفات

- الأرشيف الكبير ونسخة العمل المؤقتة: `/tmp/thesis-reference-archive.7z` بعد اكتمال التنزيل والتحقق.
- مكتبة الاستخراج المنظمة المقترحة: `/home/user/thesis-reference-library/`.
- هذا المجلد داخل المستودع مخصص للفهارس والتقارير والبصمات وروابط المصادر، وليس لرفع مئات ملفات PDF أو عدة GiB إلى Git.

## الفهارس المخطط لها

- `archive_contents.csv`: المسار داخل 7Z، النوع، الحجم المضغوط وغير المضغوط.
- `pdf_inventory.csv`: اسم الملف، بصمته، عدد الصفحات، اللغة/العنوان المستخرج، وصلاحية القراءة.
- `source_usage.md`: المرجع، موضع استعماله في المذكرة، الادعاء الذي يسنده، وسبب اختياره.
- `external_sources.md`: المراجع التي لا توجد في الأرشيف، مع رابط وبيانات ببليوغرافية وتاريخ الوصول والتحقق.

## قواعد الاستعمال

1. لا يكفي وجود PDF في الأرشيف لاعتباره مرجعًا صالحًا؛ يجب قراءة بياناته والصفحات المستعملة.
2. لا يُنسب عنوان أو مؤلف أو سنة من اسم الملف وحده إذا تعارض مع صفحة الغلاف أو البيانات الببليوغرافية.
3. تسجل صفحة/صفحات الاقتباس أو الفقرة المستخدمة عند بناء الاستشهاد.
4. لا تجلب نسخة خارجية إذا كانت النسخة الموجودة كاملة وصالحة ومطابقة للمصدر المطلوب.
5. أي مرجع يتعذر الحصول عليه أو التحقق منه يوضع في قائمة «غير محسوم» ولا تُختلق بياناته.
