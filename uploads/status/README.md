# حالات الرفع المجزأ

يُنشئ الخادم هنا ملفًا نصيًا مستقلًا لكل عملية رفع كبيرة. يسجّل الملف اسم الأرشيف وحجمه ومعرّف Release والعدد الكلي للأجزاء، ثم يحدّث بعد كل جزء ليوضح ما وصل وما تبقّى.

يمكن للخادم استئناف عملية `IN_PROGRESS` من هذا السجل والأجزاء الموجودة بعد إعادة التشغيل. الحالة الجاهزة فقط هي `STATUS_CODE: COMPLETE`. الحالات `IN_PROGRESS` و`INCOMPLETE` و`CANCELLED` و`DELETED` لا تمثل أرشيفًا مكتملًا متاحًا. ملفات الحالة صغيرة وتُحفظ عبر Contents API حتى تبقى مفهومة حتى لو انقطع الرفع أو أُعيد تشغيل الخادم.
